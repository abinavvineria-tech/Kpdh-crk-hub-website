# KPDH × Cookie Run Hub

A polished fan-made crossover website combining K-Pop Demon Hunters and Cookie Run.

## 🚀 Quick Start (Termux)

1. Update packages:
   ```bash
   pkg update
   ```
2. Install Python:
   ```bash
   pkg install python
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the app:
   ```bash
   python app.py
   ```
5. Open your browser and go to: `http://localhost:5000`

## 🛠️ Features
- Mobile-first Glassmorphism UI
- Dynamic Search & Favorites (LocalStorage)
- Theme switching (Dark, Light, KPDH, Cookie)
- Automatic Event Status calculation
- PWA ready
- Fan-made content

## 🎨 Visuals
- Neon Purple, Pink, Blue palette.
- Android-optimized bottom navigation.
- Responsive grid layout.
